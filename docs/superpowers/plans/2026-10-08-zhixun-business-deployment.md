# 知讯后端业务整改：部署边界与待确认规则

日期：2026-10-08。本轮没有部署、迁移真实数据库、连接真实 Redis/OpenSearch/RabbitMQ 或调用真实 AI。

## 已确认并恢复的返回契约

用户确认后台评论列表保留作品标题。恢复 CommentVO.articleTitle（String / getter / setter / articleTitle JSON 字段）；原有批量标题查询及文章缺失时空串回退保持不变。其他未提交改动保留。

## AI 结果及群组任务

- 写作/摘要/审核 HTTP 消费者、私聊与群组回复共用结果校验：null、空最终文本及 error: 使用标识不被当作正常成功内容；错误经原有业务异常格式返回 503。
- 不把 reasoning_content 当作最终回复。
- 现有图片实现只是占位文本，当前明确返回未接入/503，而不是假称生成图片；本轮没有实现真实图像提供方接口。真实模型及计费配置需另行验证。
- 群组任务分离接收、执行、结果校验、条件落库和通知，保留现有异步 HTTP 接收/CHAT 成功消息契约。
- 接收请求和开始执行时校验正常群组/当前成员；最终 SQL INSERT 也要求群组正常且请求者有成员记录。零行写入不得广播成功。
- 使用独立、有界、受 Spring 生命周期管理的任务池，不抢占应用通用 @Async 执行器。

可配置资源参数（不是收费/用户业务额度）：

```properties
zhixun.ai.group-tasks.core-size=2
zhixun.ai.group-tasks.max-size=4
zhixun.ai.group-tasks.queue-capacity=32
```

满队列使用现有 503 业务错误；不采用 CallerRuns 将耗时模型调用压回 HTTP 请求线程。

## WebSocket 权限

房间订阅共用正常群组/成员校验，未验证通过不能加入。正常聊天/AI 广播根据最新群成员列表过滤，已退出者和已解散群组不能继续收到正常内容。错误仅发送给原请求者的房间连接，使用既有 ERROR/data.message 协议，不把错误落成聊天记录。

原有静态房间注册结构暂时保留，权限依赖随 handler 初始化/销毁；依赖未初始化、查询失败或关闭群组时广播失败关闭。本阶段没有改变禁言、计费、用户配额和历史归档规则。

既有前端 ERROR 接收与 AI 加载状态没有完整关联；加载指示器的失败收尾仍需后续前端配合。本轮没有伪造 ai_reply 消息来清除指示器，也没有修改前端。

## 文章提交与定时发布

搜索/图片索引、关注信息流、缓存/版本以及审核通知的外部动作安排在最外层事务成功提交后；事务回滚不执行。捕获 ID、作者、时间和已组装通知，避免以后读取可变实体。

外部失败被隔离，不把已经提交的数据库写入变成接口失败；文章键缓存、信息流缓存与版本递增也独立尝试。

定时发布改为状态专用条件更新：最新状态仍为 PENDING、未删除、发布时间存在且已到期。不会用陈旧整行覆盖并发驳回、重新排期或内容编辑。成功更新后读取必需元数据失败会使事务回滚，不静默提交发布状态而跳过同步。数据更新后采用最新仍到期的时间进行信息流推送。

这不是事务 outbox 或持久化重试，不保证崩溃/外部停机/跨事务乱序后的最终一致性。外部恢复和重建流程仍需单独整改。

## 必须确认的审核/定时规则

当前代码同时用 PENDING 表示待审核和等待定时发布。草稿定时发布与命中敏感词后的待审核内容因此可能进入同一到期发布路径。本轮只修复条件写与提交时序，**没有认定这种审批语义正确，也没有新增或选择审批政策**。

需要确认：命中敏感词而进入待审核的内容，即使设置了定时发布时间，是否必须审核通过后才能发布？确认后再设计不混淆审批与排期的状态/数据模型，并处理历史数据，不能默默把旧 PENDING 全部视为已批准。

## 验收与生产限制

新增测试使用 Mockito、真实 MyBatis 和隔离 H2，未连接生产资源。H2 不证明目标 MySQL 的 JSON、生成键、事务隔离、权限撤销并发时序和死锁行为。上线前要在隔离 MySQL/Redis/OpenSearch/消息服务中做多角色端到端验收。

没有新建生产表或改变既有表结构；SQL 方法依赖现有 cms_group_info/cms_group_member/cms_group_message/cms_article 字段。部署前仍要确认线上结构与源码契约一致。

群组任务暂存内存，重启可丢失已接收任务；没有持久任务状态、取消/重试/去重、每用户额度或可靠通知记录。还未进行真实模型内容质量/敏感词安全验收。整个知讯平台、其它两个项目及全面整改目标均未宣称完成。
